# 🎮 Survival Arena

 ![Survival Arena](/images/banner.png)

A 2D survival game built with Python and Pygame.

Collect resources, craft weapons, survive enemy waves and defeat powerful bosses.

This project is developed as a learning project by young developers using Python, Visual Studio Code and AI coding assistants.

---

## 🚀 Features

Current and planned features:

- ✅ Player movement
- ✅ Enemy AI
- ✅ Loot collection
- ⏳ Inventory system
- ⏳ Crafting system
- ⏳ Weapons and upgrades
- ⏳ Boss battles
- ⏳ Highscore system

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/<your-account>/survival-arena.git
```

Change into the project directory:

```bash
cd survival-arena
```

Install dependencies:

```bash
pip install pygame
```

Start the game:

```bash
python main.py
```
