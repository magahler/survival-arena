# 🎮 Survival Arena – 8 Week Project Plan

## Overview

**Project Duration:** 8 Weeks  
**Team:** 2 Young Developers + 1 Coach (Dad)  
**Technology Stack:**

- Python
- Pygame
- Visual Studio Code
- GitHub
- Claude / GitHub Copilot

**Project Goal:**

Build a fun 2D survival game while learning programming, game development, teamwork, problem solving, and AI-assisted software development.

# 🤖 AI Development Rules

Before asking an AI assistant:

1. Describe the problem.
2. Explain what you tried.
3. Guess what might be wrong.
4. Ask for help.
5. Understand the answer before using it.

### Rule

Never ask:

> "Build the entire game."

Instead ask:

> "Help us solve the next problem."
